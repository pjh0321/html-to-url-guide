HTML 파일 하나를
웹 주소로 만드는 법

AI가 만들어준 HTML, 동료에게 보여줄 때마다 파일로 보내기 번거롭죠.
GitHub Pages를 쓰면 클릭 한 번으로 열리는 웹 주소가 생깁니다.
코딩 지식 같은 건 전혀 필요 없어요.

준비물 HTML 파일, 이메일 비용 무료

00 — Before You StartGitHub 계정 만들기

GitHub은 전 세계 개발자들이 코드를 모아두는 창고 같은 사이트예요. 그 창고를 그대로 "웹페이지처럼 보여주는 기능"이 GitHub Pages고요.

  1. github.com 접속 → 우측 상단 Sign up
  2. 이메일, 비밀번호, 아이디(username) 입력
    → 이 아이디가 웹 주소에 들어가니까 짧고 깔끔한 영문으로
  3. 이메일 인증 코드 입력하면 완료
!
아이디 ≠ 이메일

GitHub "아이디"는 영문 username이에요. 이메일 주소가 아닙니다. 로그인 후 우측 상단 프로필 아이콘 누르면 맨 위에 @무언가 형태로 보여요.

01 — Step One (1/2)저장소 만들기 시작하기

"저장소(Repository)"는 파일들을 모아두는 폴더예요. 웹페이지 하나당 저장소 하나라고 생각하면 됩니다.

본인 프로필 페이지로 가면 우측 상단에 + 아이콘이 보여요. 그걸 누르면 메뉴가 뜨고, 거기서 New repository를 선택하세요.

↑ 우측 상단 + 또는 오른쪽 끝 초록색 New 버튼 — 둘 다 같은 곳으로 갑니다

01 — Step One (2/2)저장소 정보 입력

  • Repository name: 영문 소문자 + 하이픈 (예: my-first-page) — 이 이름이 그대로 웹 주소에 들어갑니다
  • Choose visibility: 기본값 Public 그대로 두세요 (무료 Pages는 공개 저장소만 가능)
  • Add README: 토글을 On으로 (기본값이 On이라 그대로 두면 됨)
  • Description, .gitignore, license는 모두 비워두거나 기본값
  • 맨 아래 초록색 Create repository 클릭

02 — Step TwoHTML 파일 올리기이름을 index.html로 바꾸는 게 핵심

✕
기획안_v2.html 한글, 언더스코어
✕
Index.html 대문자 I
✕
index.html.html 확장자 중복
✓
index.html 이거 하나만 정답

index.html은 "이 폴더의 대문 파일"이라는 약속된 이름이에요. 이 이름으로 올려야 주소 끝에 파일명 안 붙여도 자동으로 열립니다.

이름 바꾸기: 내 PC에서 파일 우클릭 → 이름 바꾸기 → index.html 입력 → 엔터. 확장자(.html) 빼먹지 않게 주의.

02 — Step Two (계속)파일 업로드 방법

저장소가 만들어지면 이런 화면이 나와요. 우측 Add file 버튼을 누르면 드롭다운이 뜨고, Upload files를 선택하면 업로드 화면으로 갑니다.

  1. Add file → Upload files 클릭
  2. 이름 바꾼 index.html 파일을 화면에 드래그
  3. 화면 아래 초록색 Commit changes 클릭

03 — Step ThreePages 켜기파일만 올린다고 끝이 아니에요

저장소 상단 메뉴에서 Settings → 왼쪽 사이드바 아래쪽 Pages 클릭. 아래처럼 설정하세요.

  • Source: Deploy from a branch
  • Branch: main, 폴더: / (root) → Save 클릭
  • 1~2분 후 상단에 "Your site is live at..."과 URL이 뜸 (위 스크린샷에 보이는 것처럼)
!
저장소의 Settings예요

우측 상단 프로필 옆 Settings가 아니라, 저장소 페이지 안의 Settings 탭입니다. 헷갈리기 쉬워요.

04 — Step Four주소 확인하고 공유

주소는 이런 형태예요.

https://아이디.github.io/저장소이름/
↓ 아이디가 "pjh0321", 저장소가 "my-first-page"라면
https://pjh0321.github.io/my-first-page/

이 주소를 그대로 카톡, 슬랙, 이메일에 붙여넣으면 끝. 받는 사람은 GitHub 계정 없어도 클릭만 하면 열립니다.

i
끝에 슬래시(/)는 있어도 없어도 동일

.../my-first-page와 .../my-first-page/ 둘 다 같은 페이지로 열립니다.

Troubleshooting404가 떴을 때

가이드대로 했는데 404? 십중팔구 아래 셋 중 하나예요.

  1. Pages 활성화를 안 했다 — Step 03을 빠뜨리는 경우가 정말 많아요. Settings → Pages 가서 Branch 지정하고 Save 눌렀는지 확인
  2. 파일 이름이 index.html이 아니다 — 저장소 메인 파일 목록에서 정확한 철자 확인. 한글이나 대문자 섞이면 안 열려요
  3. 아직 반영 중 — 저장 직후 1~2분은 기다려야 해요. 새로고침 한 번 더!

Troubleshooting그 외 자주 막히는 곳

  • 글자 깨짐
    HTML 파일 안에 <meta charset="UTF-8">이 없을 때. AI가 만든 거면 보통 들어있어요
  • 이미지 안 보임
    HTML이 외부 이미지를 필요로 하는데 그것까지 안 올렸을 때. 이미지 파일도 같은 저장소에 함께 업로드
  • "name already exists" 에러
    같은 이름 저장소가 이미 있다는 뜻. 다른 이름으로 변경
  • Pages 항목이 안 보임
    저장소가 Private이면 무료 계정은 제한될 수 있음. Public으로 전환

05 — Maintenance나중에 수정하고 싶을 때

AI한테 다시 시켜서 HTML을 새로 받았다? 같은 저장소에 갈아끼우면 끝이에요. 주소는 그대로 유지되니까 동료에게 다시 공유할 필요 없습니다.

  1. 저장소 메인 화면에서 index.html 클릭
  2. 우측 상단 연필 아이콘으로 직접 수정 가능
  3. 또는 Add file → Upload files로 같은 이름 덮어쓰기
  4. Commit changes 후 1~2분 기다리면 새 내용 반영
i
새 내용이 안 보일 때

브라우저가 옛날 페이지를 캐시로 들고 있을 수 있어요. Ctrl+Shift+R (맥은 ⌘+Shift+R)로 강력 새로고침.
